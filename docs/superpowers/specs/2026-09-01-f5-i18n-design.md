# F5 — i18n: Locale Indonesia + String Fitur Baru

**Bagian dari:** openGym Coach Features (lihat `2026-09-01-opengym-coach-features-design.md`)
**Status:** Draft
**Effort:** Sedang

---

## 1. Tujuan

1. **Tambah bahasa Indonesia (`id`)** ke openGym — menjadi bahasa ke-13.
2. Semua string baru dari F1–F4 (rule messages, hint, panel AI, tombol "Jelaskan", "AI bantu isi", dsb.) tersedia di **semua locale** yang ada.
3. AI (F3/F4) mengikuti bahasa UI (dikirim sebagai `lang` di request).

---

## 2. Konteks i18n openGym

- `lib/i18n.js`: English source string = **key**; locale file (`src/locales/*.js`) memetakan key → terjemahan, lazy-loaded via `import.meta.glob`.
- `t(s, ...args)` mengganti `{0}`, `{1}` + English fallback (jika key tidak ada di dict → tampil English source).
- `LANGS` — daftar bahasa UI (ditampilkan di Settings).
- `INSTR_LANGS` — bahasa yang punya pack instruksi exercise (dari upstream). Kalau tidak → instruksi fallback English.
- `DATE_LOCALES` — locale untuk formatting tanggal.
- Locale packs otomatis ter-load dari `../locales/*.js` — **cukup tambah file `id.js`**, tidak perlu ubah glob.

### Keputusan (dikonfirmasi user)

| Keputusan | Nilai |
|---|---|
| Kelengkapan id.js | **Lengkap semua string** (~557 key) |
| Instruksi exercise | **Tetap English** — `id` tidak masuk `INSTR_LANGS` (upstream tidak punya pack Indonesia, `build-instructions.mjs` cuma generate 9 bahasa) → konsisten dengan de/pt |

## 3. Implementasi — Tambah Bahasa Indonesia

### 3.1 File baru: `frontend/src/locales/id.js`

Terjemahan lengkap (~557 key), dibangun dari locale yang ada (misal `es.js`/`tr.js` sebagai template struktur) dengan terjemahan Bahasa Indonesia natural.

Header mengikuti pola locale lain:
```js
// Indonesian UI strings. Keys are the English source strings (see lib/i18n.js).
export default {
  // --- generic ---
  'Confirm': 'Konfirmasi',
  'Cancel': 'Batal',
  'Delete': 'Hapus',
  'Save': 'Simpan',
  // ... dst
}
```

### 3.2 File berubah: `frontend/src/lib/i18n.js`

```js
export const LANGS = {
  en: 'English', de: 'Deutsch', es: 'Español', fr: 'Français', it: 'Italiano',
  pt: 'Português', pl: 'Polski', tr: 'Türkçe', ru: 'Русский', zh: '中文',
  ko: '한국어', hi: 'हिन्दी', id: 'Bahasa Indonesia'
}
// INSTR_LANGS: TIDAK ditambah 'id' — instruksi exercise fallback English
const DATE_LOCALES = {
  // ... en: 'en-GB', ..., id: 'id-ID'
}
```

- `LANGS` → otomatis tampil di Settings (`Object.entries(LANGS).map`).
- Settings akan menampilkan subtitle "Exercise instructions aren't available in this language yet" untuk `id` (karena tidak di `INSTR_LANGS`) — perilaku yang diinginkan.
- `localePacks` glob → `id.js` otomatis ter-load.

## 4. Implementasi — String Fitur Baru F1–F4

### 4.1 Prinsip

- Semua string baru pakai `t('English source', ...)` sebagai key (pola existing).
- Tambahkan terjemahan ke **semua** locale yang ada (12 + id = 13), bukan hanya English.
- String yang belum diterjemahkan → fallback English (t() sudah menangani) — tidak memblokir.

### 4.2 Daftar string baru (per fitur)

**F1 (muscle map filter):**
- `'By muscle'` / `'Muscle'`
- `'All muscles'` (tombol clear)
- `'{0} exercises train {1}'` (subjudul hasil)

**F2 (rule engine / coach hints):**
- `'Set variance'` — title hint
- `'Rep drop'` / `'Plateau'` / `'Substitution'`
- `'Hold — targets not met'`
- `'Repeat this weight next week'`
- `'Deload 10%'`
- `'Evaluate — substitute or review your plan'`
- `'Try an intensity technique (rest-pause / drop set)'`
- `'Substitute to a variation working the same muscles'`
- `'Take a full deload week'`
- `'Calibrate — log 1-2 sets and adjust'`

**F3 (AI explainer):**
- `'Explain'` / `'Why?'`
- `'AI explanation'`
- `'Ask a follow-up…'`
- `'AI not available offline'`

**F4 (AI custom exercise):**
- `'Fill with AI'` / `'AI help'`
- `'Describe the exercise…'`
- `'Edit the fields before saving'`
- `'Something looks off — you can edit before saving'`

### 4.3 AI mengikuti bahasa UI

- Frontend kirim `getLang()` sebagai `lang` di body request `/api/explain` & `/api/exercise/suggest`.
- Server teruskan `lang` ke `callAI` sebagai instruksi bahasa (system prompt / user prompt).
- Untuk bahasa tanpa dukungan LLM yang baik (opsional), fallback: kirim `'en'` — keputusan bisa per-provider.

---

## 5. Testing

- **Smoke test:** script yang memverifikasi tiap key `t('...')` yang dipakai punya entry di tiap locale (atau fallback English — tidak error).
- **Manual:** ganti bahasa ke `id` → seluruh UI terjemahan; instruksi exercise English; subtitle "not available" tampil di Settings.
- **F1–F4:** string baru muncul terjemahan di tiap locale, fallback English untuk yang belum.
- **AI:** request `/api/explain` dengan `lang:'id'` → output LLM Bahasa Indonesia.

---

## 6. Out-of-Scope

- Pack instruksi exercise Indonesia (`instr/id.js`) — upstream tidak punya; fallback English (keputusan user).
- Terjemahan sempurna semua string — fallback English cukup untuk yang belum.
- Bahasa baru selain Indonesia.
